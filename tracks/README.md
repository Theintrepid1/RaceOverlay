# Built-in track library

One JSON file per track, shipped inside every build. Race Analysis reads
these alongside the tracks saved on each computer; a local edit to one of
these overrides it (same file name) until "Reset to built-in".

To add or update a track: in Race Analysis, Track tab, "Export for
sharing…", then put the file here (keep the file name: it's the track's id,
so it must match what's already here for an update).

What goes in: name, start/finish line, turn names and positions. What
doesn't: map images. Official track maps are the tracks' own artwork, so
they stay on each user's machine and are never committed here.
